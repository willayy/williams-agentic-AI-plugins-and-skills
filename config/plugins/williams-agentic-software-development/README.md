# Agentic Software Development Plugin

A Gemini and Antigravity plugin bundling programming instructions, architectural patterns, and Git workflows.

## Plugin Rules

- `rules/AGENTS.md`: Language-agnostic coding standards (SRP, encapsulation, Law of Demeter, line limits), default argument restrictions, and Conventional Commits instructions.

## Bundled Skills

- `add-commit-push`: Make several different git adds, commits, and pushes with fitting messages.
- `python-programming`: Python styling and design rules complementing PEP standards.
- `react-programming`: React and TypeScript guidelines utilizing MVVM, dependency injection, composition, and colocation.
- `relational-database`: Checklist for designing, altering, and validating relational databases.
